# 文档中心

> 最开始是为了管理项目文档，现在是ai可以无缝衔接的工作流程
>
> 通过提示词让ai每一次修改都记录文档，目的是为了更好的版本管理。

- 左栏项目 → 中栏文件 → 右栏阅读/编辑，三栏即全部界面
- 每个项目自带「开工卡」（简报）和「档案」（更新日志），AI 换窗口不换记忆
- 知识库 = 个人记忆（7 份小文件）+ AI 规矩 + 13 个 Godot/游戏设计技能 + 项目简报模板
- 全部数据在 exe 旁边文件夹里，**不进注册表、不联网、不要数据库**——拷走文件夹就是搬家，删掉就是卸载

| 功能 | 干什么用 |
| --- | --- |
| **个人记忆** | 拆成 7 份小文件（我是谁/学过什么/问过什么/还没懂什么/英文词/资料），在程序里一份份单独编辑，AI 开工先读 |
| **注入知识库** | 把你的「大脑」复制进任何项目文件夹，那边的 AI 立刻认识你、守你的规矩。核心包（秒完成）或全量包（带技能库）两档 |
| **从 zip 导入** | 拿到别人分享的 知识库.zip 一键装进程序。**已有的文件绝不覆盖**——你填过的记忆不会被空模板冲掉 |
| **项目归档** | 做完的项目右键归档：从列表消失、记录留底，随时重新启用；确定不要了才彻底删除 |
| **文档/项目分家** | 学习文档自动收进设置页（搜索照样搜得到），左栏只留真项目 |
