# 文档中心 · 第一次使用说明

**这是什么**：把散落各处的文档、日志集中到一个窗口里看和搜的桌面小工具，自带一套「AI 大脑」（知识库）。
界面三块：左边项目列表 → 中间文件列表 → 右边内容显示（Markdown 自动排版）。

## 怎么开始（三步）

1. 把整个「文档中心」文件夹解压到任意位置（比如 D 盘或桌面都行），**别放进 `C:\Program Files`**（那里受系统保护，程序存不了数据）。
2. 双击「文档中心.exe」。第一次打开会自动在旁边建「数据」「项目档案」两个文件夹，都是空的，正常。
3. **装大脑**：设置 → ② 知识库 → 「从 zip 导入…」，选仓库根层的 `知识库.zip`——程序自动解压到 exe 旁、自动认出结构，一键完成。
4. 点左下角「＋ 新建项目」，填三样：名字（随便起）、类型（下拉选一个）、文件夹路径（点「浏览」选你放文档的文件夹）。建好就能看、能搜了。

## 知识库：这个软件的「AI 大脑」

知识库是给 AI 软件读的「大脑」，用第 3 步从 `知识库.zip` 导入后就装在 exe 旁边（`知识库\` 文件夹）：

| 在哪 | 是什么 |
| --- | --- |
| `知识库\知识库总索引.md` | 总入口，AI 先看这张表 |
| `知识库\个人记忆\`（7 份小文件） | **你的个人记忆**：00-总索引 / 01-我是谁 / 学了什么 / 问过什么 / 还没懂什么 / 英文词 / 资料。一份一个方面，在文档中心里单独打开编辑 |
| `知识库\给AI的规矩\` | 全局规范：汇报规矩、时间戳格式——AI 照着做，记录才规整 |
| `知识库\技能库\` | 13 个现成技能：6 个 Godot 开发 + 7 个游戏设计，复制进 AI 软件的 skills 目录就能用 |
| `知识库\项目记忆\` | 项目简报模板——让 AI 记住你的项目做到哪了，不再每次重新读一遍几百行的日志 |

建议第一次用就把 `知识库\个人记忆\` 里的几份填成自己的记忆档案（先填 01-我是谁，最重要），以后 AI 干活前都先读它们。设置里「编辑个人记忆」按钮直接打开总索引。

**只有 zip 没有文件夹？——「从 zip 导入」**：拿到一个 `知识库.zip`（别人分享的大脑压缩包）时，设置 → ② 知识库 → 「从 zip 导入…」，选那个 zip 就行：程序自动解压到 exe 旁、自动认出里面的知识库结构（整包带不带外面那层文件夹都认得）、自动把知识库路径指过去。**已有的同名文件一律跳过**——你填过的个人记忆绝不会被压缩包里的空模板冲掉。

**把大脑带去别处——「注入知识库」**：设置 → ② 知识库 → 「注入知识库…」。选一个目标文件夹（比如你另一个项目的文件夹），再选带多少东西：

**把大脑带去别处——「注入知识库」**：设置 → ② 知识库 → 「注入知识库…」。选一个目标文件夹（比如你另一个项目的文件夹），再选带多少东西：

| 档位 | 带什么 | 什么时候用 |
| --- | --- | --- |
| 核心包 | 总索引 + 给AI的规矩 + **个人记忆（空白模板）** + 项目记忆模板 | 让那边的 AI 认识你、守你的规矩，秒完成 |
| 全量包 | 核心包 + 全部技能库（文件多、体积大） | 那边要干 Godot / 游戏设计的活 |

注入会在目标文件夹放两份：顶层散一份（AI 顺手就能读到）+ `知识库\` 完整文件夹一份。**已有的同名文件绝不覆盖**——你填好的个人记忆不会被空模板冲掉。

用别的 AI 软件（Claude Code、Trae、Cursor 等）干活时，对它说一句：「我的知识库在 <这里>\知识库，先读里面的知识库总索引.md」就行。
想换位置：顶栏「设置 → ② 知识库 → 浏览…」，换成任何文件夹。

## 数据存在哪（重要）

你的所有数据（项目清单、备忘录、学习笔记）都存在 **exe 旁边的文件夹里**，一个字节都不进系统注册表。

- **换电脑**：把整个「文档中心」文件夹拷走就行。
- **不要了**：删掉整个文件夹，干干净净。

## 第一次打开可能遇到的小提示

| 情况 | 说明 |
| --- | --- |
| Windows 蓝底警告「未知发布者」 | 点「更多信息 → 仍要运行」。因为作者没买数字签名证书（一年几百上千元），不是病毒；介意的话可以扫描后再运行 |
| 左边预置的两个示例项目标「路径不存在」 | 那是原作者电脑上的文件夹，在你机器上自然没有。右键删掉，或编辑成自己的路径 |
| 「我的花园」打分 | 现在用**本地词库**打分（按内容字数和干货密度给分），不联网、不用填任何密钥 |

## 里面还有什么

- 顶栏「看改动」：按日期看每个项目的改动记录。
- 搜索框：跨所有项目搜文件内容，结果精确到行。
- 「备忘录 / 学习笔记」：两页自动保存的笔记（在右栏首页和顶栏）。
- 「我的花园」：学习打卡小游戏，学了知识让 AI 打分换水滴浇树。
- **文档项目自动收进设置**：学习文档、通用文档这类项目不在左栏挂占地方（搜索和「看改动」照旧能搜到它们）；想让某个项目常驻左栏，去 设置 → ③ 隐藏的文档 →「在左栏显示」。任何项目也能右键 →「从左栏隐藏」。
- **换欢迎插画**：设置 → ① →「更换欢迎插画…」，选一张自己的图立刻换上（旧图自动备份成 欢迎插画.旧.bak）。
- **项目归档**：项目做完了？右键项目 →「归档这个项目」（编辑弹窗里也有同款按钮）。它从列表和搜索里消失，改动记录搬进 `项目档案\_已归档\` 留底（硬盘上的项目文件一个不动）。底部「已归档」分组里右键可「重新启用」；确定永远不要了，还有「彻底删除…」（连改动日志一起删，不可恢复，弹窗会列清楚删什么）。

祝使用愉快！程序用 Python + PySide6 编写，欢迎研究改造。
