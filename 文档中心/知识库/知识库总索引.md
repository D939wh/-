# 知识库总索引（示范版）

> **这是什么**：这个文件夹是给 AI 读的「大脑」。任何 AI 软件做项目前，先看这张表定位要用的东西。
> **怎么用**：新装了 AI 软件就把对应技能文件夹复制进它的 skills 目录；做项目前读对应文档；项目多了照第二节的样式给每个项目建简报。建立【2026-10-28 16:55】。

## 一、这里有什么

| 位置 | 内容 | 谁用 |

## 二、AI 开工流程（照抄就能用）

1. 先读 `个人记忆\` 里你填好的记忆档案（还没填就先照模板填一份）：AI 得先知道你是谁、会什么。
2. 读项目根目录（或 `项目记忆\`）的 `_项目简报.md`：这是什么 / 做到哪 / 下一步 / 别碰什么。
3. 要历史细节：去 `项目档案\<项目名>\项目更新日志.md` 搜 `## 【` 按日期定位，只读那一段。
4. 收工前把简报的「现在做到哪 / 下一步」覆盖重写（不追加，追加会撑爆）。
5. 每次改完代码往日志最前面加一条：计划 / 实际做了 / 动了哪些文件 / 怎么验证 / 新概念。

## 三、怎么把这个大脑装进别的 AI 软件

技能库每个技能是一个文件夹（内含 SKILL.md）。复制到对应软件的技能目录，重启软件：

| 软件 | 技能目录（Windows） |
| --- | --- |
| Claude Code | `C:\Users\<你的用户名>\.claude\skills\` |
| Trae | `C:\Users\<你的用户名>\.trae-cn\skills\` |
| Cursor | `C:\Users\<你的用户名>\.cursor\skills\` |
| Codex | `C:\Users\<你的用户名>\.codex\skills\` |
## 四、怎么加新技能包

技能库是活的，以后随时加。四步：

1. **建文件夹**：`技能库\<分类>\<技能名>\`。开新分类就建新编号文件夹（现有 02-Godot开发技能、03-游戏设计技能，比如美术的可以叫 04-美术技能）。
2. **写 SKILL.md**（唯一必需的文件）：开头两行元信息——`name`（英文短名）和 `description`（这段技能干什么用 + 什么**时候**该用它）。**description 是 AI 按需调用的依据，写得越准，AI 调得越对**。正文写：什么时候用 / 什么时候别用（指路去别的技能）/ 工作流程。
3. **可选子文件夹**（按需）：`references\` 深入资料、`templates\` 成品模板、`evals\` 测试用例、`examples\` 示范。没有硬性要求，小技能一个 SKILL.md 就够。
4. **登记两处 + 重打包**：本文件第一节表格加一行（顺手改技能总数）；注入/分享前重打 zip。

登记忘了做不报错，但 AI 会「看不见」这个新技能——它只认索引里有的东西。
